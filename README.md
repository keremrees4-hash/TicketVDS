# Ticket Bot

## Kurulum
```bash
npm install
node bot.js
```

## Komutlar
- `!setup` — ticket panelini bu kanala gönderir
- `!setstaffrole @rol` — staff rolünü ayarlar (ticket açılınca ping atar)
- `!setlog #kanal` — log kanalını ayarlar (transcript buraya gider)

## Nasıl Kullanılır
1. `.env` dosyasına token'ını yaz
2. `npm install` çalıştır
3. `node bot.js` ile başlat
4. İstediğin kanalda `!setup` yaz
5. Panel gelir, hazır!
